# Chorequest

A cozy single-file RPG that turns household chores into a little quest game.

Turn weekly and monthly chores into a game: earn XP, keep your streak alive, unlock badges and level up every time you clean.

## Features

- **Level up** your character by completing chores
- **Streaks** with freeze protection so missed days don't end everything
- **Badge chains** across streaks, completions, levels, XP, rewards, and perfect weeks
- **Reward shop** — save coins and claim real-life treats
- **Cosmetics shop** — themes, card frames, and particle palettes
- **Daily reminders** with a gentle, time-aware voice
- **Ambient background** with drifting gradient and floating particles
- **Sound effects** (muted by default, easy to toggle)
- **Export / import** your save as JSON
- **PWA-ready** with manifest and service worker stubs

## Run it

Open `index.html` in a browser. That's it — single file, no build step.

## Project files

- `index.html` — the whole app (HTML + CSS + JS in one file)
